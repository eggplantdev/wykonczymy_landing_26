# Live-site SEO harvest

What the WordPress site actually serves in `<head>`, taken verbatim so the new site's copy decisions
argue against real strings rather than a memory of them. **This is a snapshot, not a spec** — the
live site is still the published site and can change under it.

Every page carries `robots: max-image-preview:large`, an All in One SEO JSON-LD graph
(`Organization`, `WebSite`, `WebPage`, `BreadcrumbList`, `ImageObject`), and `og:image` pointing at
`wp-content/uploads/2023/10/cropped-favicon.png` — a favicon, on all twelve.
